/* Functions 
         Input value/s --> functions --> Output value/s
   A Built-in SQL code :
    - accepts an input value
    - processes it
    - return an output value
   We have 2 Categories
   1. Single-Row Functions : Accepets single row values and outputs the single value
                            Ex: 'MARIA' -> Lower() -> 'maria'
   2. Multi-Row Functions  : Accepts multiple row values and outputs a aggregated result 
                             10,20,30 -> SUM() -> 60
   Types of Functions : 
   1. Single Row Functions  ->   String Functions
      (Row-Level-Calculations)   Numeric Functions
                                 DateTime Functions
                                 NULL Functions
   2. Multi Row Functions   ->   Aggregate Functions (Basic)
      (Aggregations)             Window Functions (Advanced)
   - Single Row functions are used to manipulate and prepare data for second group(Multi Row functions).
   - So we clean up, transform and prepare the data for analysis.
   - And for Analysis we use the Multi Row Functions.
*/
